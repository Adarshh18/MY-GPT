## 🌌 Overview

- **MY-GPT** is a cutting-edge web application that integrates the power of OpenAI’s GPT model with the flexibility of **Next.js**.  
It delivers lightning-fast responses, beautiful dark-themed UI, and a fully serverless setup ready for deployment on **Vercel**.

> 💡 Think of it as your own AI workspace — talk, code, and create with your personalized GPT interface.

## ⚙️ Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Adarshh18/MY-GPT.git
cd MY-GPT
```
### 2️⃣ Install Dependencies
```
npm install
# or
yarn install
```
### 3️⃣ Configure Environment Variables
Create a .env.local file and add:
```
NEXT_PUBLIC_APP_NAME=MY-GPT
OPENAI_API_KEY=your_openai_api_key_here
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```
### 4️⃣ Run the App
```
npm run dev
# or
yarn dev
```
---
### 🌐 Deployment (Vercel)

You can deploy instantly using Vercel:

- Push this repo to GitHub
- Visit Vercel → New Project → Import GitHub Repo
- Add your environment variables
- Hit Deploy 🚀
- Vercel automatically detects Next.js, sets up builds, and enables serverless APIs.
